# 拠点の候補

今のTX（と中継ではRX1）を固定したまま、登録済みの地点プリセットの中から、受信地点または中継地点としてどこが最もよく届くかを比べます。
拠点の配置を検討するための機能です。

## 操作

1. 右側でTXとRX1を選びます。メッシュでは使えません。
2. 「拠点の候補」タブで、候補の役割を選びます。
   - 受信地点（TX→候補）：RX1のアンテナ・雑音を候補地点に置いた場合のTX→候補を計算します（候補ごとにエンジン1回）。
   - 中継地点（TX→候補→RX1）：TX→候補と候補→RX1の両区間を計算します（候補ごとにエンジン2回）。
3. 地点プリセットから候補を最大10か所選びます。TXとRX1の地点、移動局は候補に出しません。
4. 「候補を比較」を押すと、目標REL以上になる時間数の多い順（同数なら平均RELの高い順）に並べます。
5. 各行の24マスは、その時刻の最良周波数のRELです。中継地点では、同じ時刻の2区間の最良RELのうち低い方を示し、マスにカーソルを合わせると各区間の周波数が見られます。
6. 計算履歴から再表示でき、CSV/JSONで出力できます。

## 仮定

- 中継局はRX1のアンテナで受信し、TXのアンテナと送信電力で再送信すると仮定します。中継局の雑音はRX1と同じ値です。
- 指向性アンテナを固定方位にしている場合、候補地点でも同じ方位を使います。相手局方向にする設定なら候補ごとに向きを合わせます。
- 中継では2区間の周波数が異なってもよいものとします。

## 限界

- RELは月間統計で、瞬時の通信可否ではありません。
- 中継局での蓄積・転送の遅延、送受信の切替、同時送信による混信、チャネル割当は考慮しません。
- 地形、周囲の雑音環境、設置条件の違いは考慮しません。候補地点の雑音はRX1と同じ値です。
- 各候補の生出力・入力カードは保存しません。必要な経路は単一RXで再計算してください。
- 公開版では1回の計算で回数制限の5回分を消費します。
