# 報告書の印刷

単一RXの24時間予測の結果を、運用の打合せや記録に使える1枚の印刷用ページにまとめます。

## 操作

1. 単一RXで「24時間の伝搬を計算」を実行するか、履歴から地点間予測を開きます。
2. 「24時間予測」タブの出力欄で「報告書を印刷」を押します。白地の別ウィンドウが開き、印刷画面が表示されます。
3. PDFが必要な場合は、印刷画面の送信先で「PDFに保存」を選びます。用紙はA4横を想定しています。

ポップアップが止められている場合は、ブラウザでこのページのポップアップを許可してください。

## 載せる内容

| 項目 | 内容 |
|---|---|
| 見出し | 作成時刻（UTC）、計算時刻（UTC）、結果ID |
| 条件 | 経路（TX→RXの地点名）、座標、回線距離・方位、対象年月、SSNと取得方法、送信電力、周波数、TX・RXアンテナ、雑音、要求SNR・目標REL、電波型式・偏波 |
| 時刻別の推奨周波数 | UTCごとに、目標REL以上で最もRELの高い周波数とREL・SNR。届く周波数がない時間は「—」とし、最もRELの高い周波数の値を赤で示します |
| 信頼度ヒートマップ | 画面の周波数×UTCの表と同じ内容です |
| 運用周波数の24時間計画 | 画面で選んでいる方針（切替を抑える／毎時最良）の計画表です |
| 注記 | 予測が月間統計であること、計算エンジンのバージョン |

文字は画面で選んでいる言語で出力します。利用者が登録した地点名・アンテナ名は登録したとおりに出力します。

## 注意

- 報告書は計算時点の結果です。条件を変えた後は再計算してから印刷してください。
- 内容は予測であり、周波数の割当や運用の許可を示すものではありません。
- ブラウザの印刷機能を使います。サーバー側でPDFは作りません。

複数RX、メッシュ、カバー範囲、12か月の見通しの結果には対応していません。
