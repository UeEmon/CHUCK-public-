# 報告書の印刷

単一RXの24時間予測の結果を、運用の打合せや記録に使える1枚の印刷用ページにまとめます。カバー範囲、Propagation Chart、ダイバーシティー、メッシュ、12か月予測、必要な送信電力、拠点の候補の各タブも、表示中の結果を同じ形式で印刷できます（[ほかの結果タブ](#ほかの結果タブ)）。

## 操作

1. 単一RXで「24時間の伝搬を計算」を実行するか、履歴から地点間予測を開きます。
2. 「24時間予測」タブの出力欄で「報告書を印刷」を押します。白地の別ウィンドウが開き、印刷画面が表示されます。
3. PDFが必要な場合は、印刷画面の送信先で「PDFに保存」を選びます。用紙はA4横を想定しています。

ポップアップが止められている場合は、ブラウザでこのページのポップアップを許可してください。

## 載せる内容

| 項目 | 内容 |
|---|---|
| 見出し | 作成時刻（UTC）、計算時刻（UTC）、結果ID |
| 条件 | 経路（TX→RXの地点名）、座標、回線距離・方位、対象年月、SSNと取得方法、送信電力、周波数、TX・RXアンテナ、雑音、要求SNR・目標REL、電波型式・偏波 |
| 時刻別の推奨周波数 | UTCごとに、目標REL以上で最もRELの高い周波数とREL・SNR。届く周波数がない時間は「—」とし、最もRELの高い周波数の値を赤で示します |
| 信頼度ヒートマップ | 画面の周波数×UTCの表と同じ内容です |
| 運用周波数の24時間計画 | 画面で選んでいる方針（切替を抑える／毎時最良）の計画表です |
| 注記 | 予測が月間統計であること、計算エンジンのバージョン |

文字は画面で選んでいる言語で出力します。利用者が登録した地点名・アンテナ名は登録したとおりに出力します。

## 注意

- 報告書は計算時点の結果です。条件を変えた後は再計算してから印刷してください。
- 内容は予測であり、周波数の割当や運用の許可を示すものではありません。
- ブラウザの印刷機能を使います。サーバー側でPDFは作りません。

## ほかの結果タブ

次のタブでも、結果の出力欄（Propagation Chartは表示欄の上）に「報告書を印刷」があります。いずれもA4横の白地のページで、見出し（作成時刻・計算時刻・結果ID）、条件、タブに表示している表と図、注記を載せます。

| タブ | 載せる内容 |
|---|---|
| カバー範囲 | 周波数・UTC・地点数、格子点を描いた回線マップ（画面の拡大・表示範囲のまま） |
| Propagation Chart | 選んでいる計算結果・受信局・表示指標と、画面と同じ図 |
| ダイバーシティー予測 | 最良サイトのRELの表、選んでいるUTCのサイト選択と理論範囲、サイト別詳細 |
| メッシュ予測 | 選んでいる周波数・UTC・中継段数でのTX×RXマトリックス（中継後のRELと↻段数）、選んでいる経路の周波数×UTCの表と中継経路 |
| 12か月予測 | 月×UTCの表と、選んでいる月の周波数×UTCの表 |
| 必要な送信電力 | 周波数×UTCの最小電力の表と、電力ごとの最良RELの表 |
| 拠点の候補 | 比較結果の表（候補の選択欄は載せません） |

表の色と印（·）は画面と同じで、目標RELと「REL表示の閾値」の設定、%／4段階の切替をそのまま反映します。表の上の行に、画面で選んでいる周波数・UTCなどを書きます。時刻や周波数を切り替えるタブは、印刷を押した時点の表示を印刷します。
