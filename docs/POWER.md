# 必要な送信電力

1つの経路（TX→RX1）について、送信電力を変えて24時間予測を繰り返し、目標RELに届く最小の送信電力を求めます。
「何Wあれば、どの時間帯に、どの周波数で届くか」を見るための機能です。

## 操作

1. 右側でTXとRXを選びます。RXが複数ある場合はRX1を使います。メッシュでは使えません。
2. 「予測条件・宇宙天気」で年月、SSN、周波数、要求SNR、目標RELなどを設定します。右側の送信電力の値は計算に使いません（表の中で目印として示します）。
3. 「必要な送信電力」タブで「送信電力を逆算」を押します。10 W、20 W、50 W、100 W、200 W、500 W、1 kW、2 kW、5 kW、10 kWの10段階で、エンジンを10回逐次実行します。
4. 上の表は周波数×UTCで、目標REL以上になる最小の段階（W）を示します。「>10k」は10 kWでも届かないことを示します。
5. 最上段の「最小電力」は、その時刻に最も小さい電力で済む周波数と電力です。同じ電力で届く周波数が複数あれば、その電力でRELが高い方を示します。
6. 下の表は電力×UTCで、各電力での時刻ごとの最良RELと、目標REL以上になる時間数を示します。現在の設定と同じ電力の行を枠で示します。
7. 計算履歴から再表示でき、CSV/JSONで出力できます。

## 限界

- 段階の間の電力は計算しません。例えば「200」は、100 Wでは届かず200 Wでは届くことを意味します。
- 電力以外の条件（アンテナ、利得補正、雑音、要求SNR、偏波損失）は計算時点の値のままです。アンテナ利得を上げた場合の効果は、アンテナを変えて再計算してください。
- RELは月間統計です。瞬時の通信可否や、送信機・電源・電波法上の許容電力は考慮しません。
- 各段階の生出力・入力カードは保存しません。必要な電力は単一RXで再計算してください。
- 公開版では1回の計算で回数制限の4回分を消費します。
