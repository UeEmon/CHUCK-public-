# ゲートウェイ管理画面

`http://localhost:18083/`で位置ゲートウェイの受信状態・最新位置・局ごとのJSON / GeoJSON / NMEA 0183（RMC・HDT・HDG・THS）設定を管理できます。日本語を含む8言語を選択できます。表示言語はこのゲートウェイのオリジンで保存します。

## 起動

既存の外部受信用・本体連携用トークンに加え、16文字以上の専用パスワードを設定します。サービス用トークンと同一値では有効になりません。

```sh
export HF_GATEWAY_UI_PASSWORD='replace-with-a-long-unique-password'
docker compose up -d --build
```

画面を開いて専用パスワードでログインします。未設定ならログインを無効化して設定案内を表示します。Composeの既定公開先はlocalhostのみです。遠隔から使う場合はHTTPSリバースプロキシを用意し、`HF_GATEWAY_UI_SECURE_COOKIE=1`を設定してください。HTTPSの転送先は同一Hostを維持する必要があります。

## 操作

1. 外部受信・本体連携の認証設定状態と最新報告を確認します。5秒ごとの一覧更新を停止することもできます。
2. 送信元、局ID、名前、船舶／航空機／車両、受信形式、有効フラグを保存します。名前は利用者入力のまま表示します。
3. NMEA 0183局をTCP・UDPで受信する場合は、局一覧の「受信キー」で発行を押し、表示されたキーを送信機に設定します（キーはその場でしか表示しません）。再発行・解除もここで行います。閉域網では受信キーの代わりに「送信元IPアドレス（TCP・UDP）」に機器のIPアドレスを入力することもできます。TCP・UDPの受信状態と件数は「ゲートウェイ状態」に表示します（[TCP・UDPでのNMEA受信](POSITION_INTERFACE.md#tcpudpでのnmea受信)）。
4. 一覧の編集で既存局をフォームに読み込みます。有効チェックの切替でも保存できます。形式・種別の変更や無効化で旧位置は破棄され、次の有効報告を待ちます。
5. 最新位置一覧でUTC観測時刻、座標、速度、針路、船首方位（来歴のHDT・HDG・THS等）、高度、有効／期限切れを確認します。位置入力そのものは従来の外部APIから行います。速度等による将来位置予測・空中伝搬補正はしません。
6. ログアウトするとセッションを破棄します。セッションは1時間で失効し、再起動またはパスワード変更でも無効になります。

ブラウザには外部受信用・本体連携用トークンを渡しません。管理用パスワードはブラウザ保存せず、入力欄を送信時に消去します（ブラウザの任意のパスワード管理機能は除く）。ランダムなHttpOnly・SameSite=StrictセッションCookie、同一Origin・JSON要求、ログイン試行制限を使います。CookieのPathは`/ui`で、既存の外部受信・本体連携APIのBearer認証は別に維持します。設定・位置データは従来と同じgateway-dataボリュームです。

## 管理画面専用API

| Method | URL | 条件・内容 |
|---|---|---|
| GET | /ui/api/session | ログイン済み／パスワード設定済みの真偽のみ |
| POST | /ui/api/login | `{password}`、同一Origin、JSON |
| POST | /ui/api/logout | `{}`、ログイン必須 |
| GET | /ui/api/status | 最新位置・局設定・有効形式・サービス設定状態、ログイン必須 |
| POST | /ui/api/stations | 従来と同じ局設定オブジェクト、ログイン必須 |

管理操作のPOSTは同一Origin、Content-Type application/json、最大8192バイト。パスワード未設定503、未認証401、異なるOrigin403、不正入力400、形式不正415、8回の失敗後15分以内の再試行429。サービスAPIの詳細は[位置入力仕様](POSITION_INTERFACE.md)を参照してください。
