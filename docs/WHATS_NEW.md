# 新機能のお知らせ

新しい機能が使えるようになったことを、利用者が画面上で気付けるようにする仕組みです。

## 利用者から見た動き

- 前回お知らせを閉じた後に追加された機能があると、地図の上に「新しい機能が○件あります。」と表示し、該当するタブに点を付けます。
  作業の邪魔にならないよう、自動でダイアログは開きません。
- 「見る」または右上の「新機能のお知らせ」で一覧を開きます。新しいものに NEW が付き、「見る」でその機能の画面へ移動します。
- 一覧を閉じるか、表示の「×」を押すと既読になり、次に機能が追加されるまで表示しません。既読の位置はブラウザ（localStorage）に保存します。
- 初めて開いたブラウザでは、直近60日に追加された機能を新しいものとして扱います。
- 一覧には初期リリース（2026-10-15）からの機能追加の履歴も日付ごとに載せています。履歴の項目は NEW の件数には数えません。
- 文字は画面の言語で表示します。

## 機能を追加するときの手順（開発者向け）

1. `app/static/whats-new.json` の**先頭**に1件追加します（新しい順に並べます）。

   ```json
   {"id":"2026-11-01-example","date":"2026-11-01","title":"機能名","text":"何ができるかを1〜2文で。","tab":"example","element":"compute-example"}
   ```

   | 項目 | 内容 |
   |---|---|
   | id | 一意な文字列。`date` で始めます |
   | date | 公開日（YYYY-MM-DD） |
   | title / text | 日本語の機能名と説明 |
   | tab | 「見る」で開くタブの `data-tab`（省略可） |
   | element | その機能の画面にある要素のid。ページに存在するときだけお知らせを表示し、新機能として数えます。省略した項目は履歴として一覧に載るだけです |

2. `title` と `text` の翻訳を `app/static/i18n-messages.js` に7言語分追加します。
3. `python3 -m unittest tests.test_whats_new` で形式と翻訳を確認します。

`element` がページにない間はお知らせを表示しないため、機能本体より先にお知らせだけがマージされても、利用者には見えません。
