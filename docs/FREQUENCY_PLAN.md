# 運用周波数の24時間計画

単一RXの24時間予測から、時間帯ごとに使う周波数を決めた計画表を作ります。
計算した周波数（最大11波）を割当周波数とみなし、その中から選びます。サーバーとエンジンの計算は変えず、
保存済みの結果をブラウザで処理するので、計算回数は増えません。

## 操作

1. 単一RXで「24時間の伝搬を計算」するか、計算履歴から地点間予測を開きます。
2. 「24時間予測」タブの「運用周波数の24時間計画」に、時間帯・周波数・REL（最低〜最高）・最低SNR・目標REL未達の時間数を表示します。
3. 「方針」で選び方を切り替えます。
4. 「CSV出力」は1時間ごとの行（hour_utc、frequency_mhz、reliability、snr_db_hz、meets_target、switch）を出力します。
5. 「印刷」は計画表だけの白地のページを別ウィンドウで開いて印刷します。ポップアップを許可してください。

## 方針

| 方針 | 選び方 |
|---|---|
| 切替を抑える（既定） | 目標REL以上になる時間数を最大にし、その中で切替回数を最少にし、さらにRELの合計を最大にする組合せを選びます |
| 毎時最良 | 各UTCでREL最大（同値ならSNR最大）の周波数を選びます。「時刻別の詳細」の推奨周波数と同じ規則です |

「切替を抑える」でも、目標REL以上の時間数は「毎時最良」より減りません。
1日の計画を毎日繰り返す前提で、23時から0時への切替も1回と数えます。
23時台と0時台が同じ周波数なら、日付をまたぐ1つの時間帯（例：18:00–06:00）として表示します。

## 限界

- RELは月間統計です。当日の電離圏の状態や混信は反映しません。
- 周波数を切り替える手間（局間の連絡、アンテナ整合の時間など）は、切替回数を減らすことでしか考慮しません。
- どの周波数も目標RELに届かない時間は、その中で最もよい周波数を示し、「目標REL未達」に数えます。
- 計画は計算時点の条件に基づきます。条件を変えた場合は再計算してください。
