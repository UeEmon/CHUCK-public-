# 2つの結果を比較

追加日: 2026-11-14

保存された地点間予測を2件選び、RELまたはSNRの差（B−A）を周波数×UTCの表で示します。
アンテナ、送信電力、月、SSNなどを変えたときに、どの時間帯・周波数がどれだけ良く（悪く）なるかを確かめるための機能です。
保存済みの結果を読むだけなので、エンジンの計算は行いません。

## 操作

1. 比べたい条件で、単一RXの「24時間の伝搬を計算」を2回以上実行します（結果は計算履歴に保存されます）。
2. 「計算履歴」タブの「2つの結果を比較」で、A（基準）とBを選びます。開いたときは、最新をB、その1つ前をAにしています。⇄ でAとBを入れ替えます。
3. 「表示」でRELの差（%）とSNRの差（dB）を切り替えます。
4. 「CSV出力」で、1時間×周波数ごとの両方の値と差を出力します（hour_utc、frequency_mhz、rel_a、rel_b、rel_diff、snr_a、snr_b、snr_diff）。

この欄は、地点間予測が2件以上保存されているときに表示します。ダイバーシティー・メッシュなどほかの種類の結果は選べません。

## 表示の内容

| 項目 | 内容 |
|---|---|
| 目標REL以上の時間 | 各UTCの最良周波数（REL最大、同値ならSNR最大）が目標REL以上になる時間数をA・Bで数えます。目標RELはAの値を両方に使います |
| 違う条件 | 年月、SSN、送信電力、TX・RXの地点とアンテナ、利得補正、雑音、要求SNR、目標REL、最低打上げ角、吸収モード、計算方式、追加偏波損失、周波数のうち、AとBで違うものだけを並べます。同じなら「計算条件は同じです。」と表示します |
| 差の表 | 両方で計算した周波数だけを行にします。緑はBが高く、赤はBが低いセルで、差が大きいほど濃くなります（RELは50%、SNRは20 dBで最も濃い色） |
| ▲・▼ | ▲はAでは目標REL未満でBでは目標REL以上のセル、▼はその逆です |

片方だけで計算した周波数は表に出さず、表の下にその周波数を示します。

## 限界

- RELとSNRは月間統計です。差は、モデルの上での条件の違いの効果を示すもので、実際の受信の改善を保証しません。
- 履歴一覧と同じく、最新100件の保存結果から選びます。
