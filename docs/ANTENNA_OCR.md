# カタログ・仕様書の生成AI OCR取込み

アンテナプリセット画面でPDF・PNG・JPEG・WebPを取り込み、OpenAI・Claude・Gemini・ローカルLLMを選択して仕様を抽出します。ローカルLLMは画像のみ対応です。Python標準ライブラリで接続し、新規の実行パッケージは追加しません。

## 設定

画面の「AI・モデル・APIキー設定」または環境変数で設定します。[AIごとのキー取得手順・自動読込み・モデル選択](AI_SETTINGS.md)を参照してください。モデルの既定値はなく、設定完了まで読取りボタンを無効化します。従来の予察はキーなしで使えます。保存したキーは画面へ返さず、Gitや配布物へ含めません。

## 操作

1. 「カタログ・仕様書を生成AIで読み取る」を開き、1ファイル（最大8 MiB）を指定。大きなカタログは対象型式のページへ分割します。任意の出典URLはHTTPSで入力し、URLからは自動取得しません。
2. 選択したAI接続先への資料送信とクラウドAPI料金を確認し、読取りを実行。同時処理1件、API待機上限120秒、自動再試行や他AIへの自動切替なし。
3. 最大10候補の仕様と根拠ページ・短い原文引用を確認。不明値は「—」。全体の網羅性は保証しません。
4. 「この候補を確認・編集」で編集欄へ転記。初期状態は参考資料のみ、基準ホイップ、利得補正0。0.1〜200 mの物理全長だけを長さ欄へ転記します。
5. 原本をダウンロードし、値・単位・対象型式を確認してチェック。モデル・寸法・設置条件等を修正できます。計算に使う場合は参考資料フラグの解除と、近似として使う確認が必要です。
6. 保存で新規プリセットを登録。読取りだけでは登録しません。再編集時も原本を確認します。同名・revision競合・上限は従来と共通です。

画面は8言語対応。メーカー名・型式・原文引用・資料言語の注記は翻訳せず保持します。

## 抽出と限界

名称、メーカー、型式、アンテナ方式、搭載・設置方式、偏波、物理全長m、電気長m、最低／最高周波数MHz、許容電力W、明記された利得dBi、注記を抽出します。PEP／連続等は注記を確認してください。

明示された単位だけを換算し、未知値・指向性を推定しないよう指示します。物理長・電気長・取付け高さ、dBdとdBi、送信電力と許容電力の混同に注意してください。電気長とカタログ利得は計算用全長・一律利得へ転記しません。機体・艦体込みパターンへの変換はしません。**AIの数値・換算・根拠ページは原本確認が必要です。** 根拠のない値はnullへ落とし、形式不正・非有限値・過大な応答・未完了／拒否応答は保存しません。

資料内の命令・リンクは読取対象データとして扱うよう指示し、APIにツールを渡しません。資料のリンクを辿る処理や命令実行はなく、結果は固定スキーマで検証し、HTMLとして解釈せず表示します。

## 保存・削除・利用条件

原本、SHA-256、ファイル名、形式、取込UTC日時、出典URL、指定モデル、抽出値・根拠をhf-dataのSQLite `antenna_documents`へ保存。プリセットは`document_ref`で資料ID・候補番号・確認フラグを保持します。最大50資料。失敗時は資料・候補・プリセットを保存しません。

保存一覧から再表示・原本ダウンロード・削除できます。参照中の原本は先にそのプリセットを削除してください。SHA-256は内容識別用で、メーカー発行や真正性の認証ではありません。本体は従来のlocalhost信頼モデルで、原本取得に個別ログインはありません。LAN公開時は利用者が資料を取得できることを考慮してください。

資料は選択した接続先へ送信されます。クラウドは各社のデータ取扱条件を確認してください。OpenAIでは`store:false`で呼び出し、Files APIへのアップロードはしませんが、一切の保持がないことを保証する指定ではありません。Claude・Geminiは各社APIへインライン送信。ローカルLLMを選択しても、そのサーバー自体の転送・ログ設定は別に確認してください。

原本・OCR引用の権利は各権利者に帰属し、本体MITライセンスが自動適用されません。原本・抽出データ・APIキーをGitや配布束へ含めず、hf-dataを配布物から除外してください。

## API

| Method | URL | 内容 |
|---|---|---|
| GET | /api/antenna-imports | 設定済み真偽・プロバイダー・指定モデル・上限・資料一覧。キーは返さない |
| POST | /api/antenna-imports | filename、media_type、data_base64、source_url（任意）、external_processing:true |
| GET | /api/antenna-imports/{id} | 抽出値・根拠・出典メタデータ |
| GET | /api/antenna-imports/{id}/source | attachmentとして原本を取得 |
| POST | /api/antenna-imports/{id}/delete | `{}`、参照がなければ削除 |

POSTは同一Originヘッダーとapplication/jsonが必須。取込本文は8 MiBのbase64表現＋8 KiBまで。入力不正400、Origin不正403、形式不正415、別資料処理中409、API未設定・失敗・無効応答502。

登録は`POST /api/presets`で`document_ref:{id,candidate_index,reviewed:true,approximation_ack:true|false}`を付けます。計算可能にする場合はapproximation_ack:trueが必要。資料ID・候補番号の存在を検証します。

原典：[PDF入力](https://developers.openai.com/api/docs/guides/file-inputs)、[画像入力](https://developers.openai.com/api/docs/guides/images-vision)、[構造化出力](https://developers.openai.com/api/docs/guides/structured-outputs)。
