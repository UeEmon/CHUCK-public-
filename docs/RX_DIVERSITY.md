# 複数RXサイトのダイバーシティー伝搬予測

単一TXから同じ送信を2〜8個のRXサイトが受信する構成を比較します。
同一のUTC・周波数・要求SNRについてサイトごとにVOACAPを実行し、
選択受信の計画に使う候補を表示します。実際の信号合成器や受信機制御ではありません。

## 操作

1. 右側でTXの地点・アンテナプリセットを選択。「予察条件・宇宙天気」で電力・年月・SSN・周波数・要求SNR・目標RELを設定します。
2. 「RXを追加」で2〜8局の地点・アンテナプリセット・雑音を設定。登録・座標編集は「地点プリセット」、モデル・利得編集は「アンテナプリセット」で一元管理します。初期都市は実施設を示すものではありません。
3. 「24時間の伝搬を計算」を実行。RX 1局なら地点間予測、2局以上ならダイバーシティー予測になります。「TXと交換」は指定RXとTXを相互交換し、他のRXを維持します。
4. 「ダイバーシティー結果」のヒートマップまたはUTC選択で詳細を確認。結果は計算時点の条件、地図は現在選択中のTX・全RXを表示します。
5. 計算履歴から再表示、CSV/JSON出力が可能。「設定を保存」で全TX/RX選択もブラウザ内に保存します。独立仮定の参考値は「予察条件・宇宙天気」で任意指定します。

## 表示する値

| 値 | 定義 |
|---|---|
| サイト別REL・SNR・受信信号 | 各経路のエンジン出力。SNRはdB·Hz、受信信号はdBW |
| REL最大サイト | RELが最大のサイト。同値ならSNR最大、両方同値なら入力順 |
| 最良REL | サイト別RELの最大値。ダイバーシティー後の推定値とは呼ばない |
| 目標REL以上のサイト数 | 月間RELが指定基準以上のサイト数。同時受信サイト数ではない |
| 少なくとも1サイト受信の理論範囲 | 各RELを周辺確率とみなした下限max(pᵢ)、上限min(1,Σpᵢ) |
| 独立仮定の参考値 | 任意指定時だけ1−Π(1−pᵢ)。相関を推定した結果ではない |
| サイト間距離 | 大円距離（API/JSON）。相関や独立性の判定には使わない |

pᵢはRELを100で除した値。例えば80%と60%なら理論範囲は80〜100%、
独立仮定のシナリオは92%です。これを実際の統合可用性92%と保証しません。
同じ場所のサイトを別名で指定することも可能ですが、独立を意味せず、
そのような配置への独立式の適用は特に非現実的になり得ます。

REL欠測・範囲外のサイトは最良サイトの候補から除き、既知サイトだけの最大RELを下限とします。
1サイトでも欠測なら全サイトの上限と独立シナリオはnull。全欠測なら最良サイト・下限もnull。
REL=0は有効値です。エンジン自体の失敗では全体をエラーとし、成功サイトだけの結果を保存しません。

## 制約

- VOACAPのRELは同じUTC・周波数で要求SNRを満たす月間の統計であり、瞬時のフェージングや実測稼働率ではありません。
- 各サイトの雑音は3 MHz基準のVOACAP入力（−dBWの絶対値100〜180、150なら−150 dBW）、利得は−20〜30 dBi。
  雑音スペクトル、地形・近傍障害物、周囲の局所干渉、実アンテナの個別指向性を自動推定しません。
- 空間相関、同じ電離層擾乱・磁気嵐・吸収等の共通要因を独立化しません。
- 受信機故障、中継IP回線・電源・中央局、遅延・切替損失を含むエンドツーエンド可用性は計算しません。
- 複数信号のSNRを足し合わせず、最大比合成・等利得合成・BER・SELCAL検出確率は予測しません。
- 現在のD-RAP/NICT/GIRO観測によるサイト別REL補正は行いません。
- NOAA自動SSNは1回選択した同じ値・出典を全サイトへ適用。外部データの既存条件は維持します。
- 追加の外部パッケージやオンライン計算サービスは使用しません。

理論範囲は周辺確率に対する数学的な包絡であり、新たなITU準拠ダイバーシティーモデルを実装したものではありません。
相関を含む精度評価には、各サイトの同時観測・受信品質記録が別途必要です。
