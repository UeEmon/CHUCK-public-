## 標準モデル

| 種類 | 初期寸法 | エンジンモデル |
|---|---|---|
| 基準ホイップ・等方性 | 寸法なし | swwhip / sample.00 |
| 垂直ホイップ | 2.4 / 5 / 7 / 10 m | IONCAP Type 22 モノポール |
| グランドプレーン | 5 m | Type 22による近似。個々のラジアルを再現しない |
| 水平ダイポール | 全長10 / 20 / 40 m、地上高10 / 10 / 15 m、主放射方向は相手局 | IONCAP Type 23 |
| 垂直ダイポール | 全長10 / 20 m、中心給電点高7.5 / 15 m | HFMUFES Type 35 |
| 水平ログペリ | 最長素子25 m、16素子、τ 0.9、給電点高20 m、水平（傾斜90°）、主放射方向は相手局 | HFMUFES Type 43 |
| 逆L | 水平部30 m、垂直部12 m、方位0°固定 | HFMUFES Type 38 |
| 傾斜ロングワイヤー（スローパー） | 線長40 m、給電点高2 m、傾斜15°、主放射方向は相手局 | HFMUFES Type 41 |

モデルは水平面で**全方向（オムニ）**のもの（基準ホイップ・等方性・垂直モノポール・垂直ダイポール）と、**指向性**のもの（水平ダイポール＝8の字の双方向、水平ログペリ＝単一方向、逆L・スローパー＝方位で利得が変わる）に分けて表示します。主放射方向の設定は指向性モデルだけに使い、全方向モデルではVOACAPへ方位0を渡します。

全長は実寸m（ダイポールは両側合計）で、周波数ごとに共振長へ自動変更しません。垂直ダイポールは下端が地面より上になる給電点高を指定します。水平ダイポールの方位は真北を0°とした**主放射方向（線に直交する方向）**で、ワイヤーの向きではありません。主放射方向は「方位を固定」か「相手局へ向ける」を選べます。「相手局へ向ける」ではTXは受信局、各RXは送信局への大圏方位をVOACAPの主ビーム方位（ANTENNAカードのbeam_main）に入れるため、地点を変えても向きが追従します。標準の水平ダイポール3件は「相手局へ向ける」で登録します。以前の版で北向き固定のまま登録された未編集の3件は更新時に一度だけ切り替え、方位などを編集済みのものは変更しません。モノポールは地表設置の近似で、設置高の変更は使いません。

地面の比誘電率13・導電率0.005 S/mを初期仮定とします。艦体を完全導体として計算する設定ではありません。地面定数・利得補正は編集可能ですが、整合器、SWR、給電損失、ラジアル、機体・艦体・周辺構造物を自動再現しません。近似モデルの計算成功は実機性能の検証を意味しません。

モデル設定の根拠は同梱上流ソースの`ioninit.for`、`mufesint.for`と次のVOACAP資料です。

- [Type 22等の寸法指定](https://www.voacap.com/2023/documents/hamcap-type1314.html)
- [放射パターンと主放射方位](https://www.voacap.com/2023/understanding/method15.html)

水平ログペリはHFMUFESのType 43（同梱`mufesint.for`/`mufesgan.for`）で、素子と給電線の結合から周波数ごとのパターンを計算します。素子長は最長素子からτ倍ずつ短くなり、素子先端角（アレイ軸と素子先端を結ぶ線の角度）でブーム長が決まります。アレイ傾斜は鉛直からの角度で、90°がブーム水平の一般的な回転型、それより小さい値は前方が低い固定傾斜型です。周波数別の利得表が必要なCCIR Type 05は、voacaplに表の生成手段がないため採用していません。

逆L（Type 38）は垂直部を地面から立ち上げて水平部へつなぐ大地上の線状アンテナで、方位はVOACAPの定義どおり水平ダイポールと同じく水平部に直交する向きです（水平部は方位±90°の線上、給電側と先端側で利得が異なります）。傾斜ロングワイヤー（Type 41）は給電点から線が上っていく大地上のスローパーで、VOACAPの主ビーム方位は線が上る向きですが、低い打上げ角の主ローブは反対の下る向きに出るため、CHUCKの主放射方位は**線が下る向き**とし、エンジンへは180°足して渡します。どちらも地上・艦船の固定設置を想定した計算で、航空機搭載（機体を相手導体とする逆L・トレーリングワイヤー・シャント／ノッチ）の特性は再現しません。航空機用は次の利得表で扱います。

## 利得表（実測・解析パターン）

航空機の逆L・トレーリングワイヤー・シャント（ノッチ）アンテナのように、機体や艦体を含めた特性が寸法モデルで表せないものは、実測またはNEC等で解析した放射パターンを利得表として登録し、基準モデル「利得表」で使います（アンテナプリセット画面の「利得表（実測・解析パターン）の登録」）。

登録画面の「記入例つきテンプレート（CSV）をダウンロード」で、各列の説明と記入例（架空の値）が入ったCSV（[`app/static/antenna-pattern-template.csv`](../app/static/antenna-pattern-template.csv)）を取得できます。値を実測・解析結果に書き換えれば、注記行は残したまま登録できます。

CSVの例（見出し行は必須、`#`で始まる行は注記）：

```csv
# P-3 airframe HF, NEC model, free space
frequency_mhz,azimuth_deg,elevation_deg,gain_dbi
2,0,0,-12.5
2,0,10,-8.1
...
```

- 周波数1〜30 MHz、方位0〜360°未満（アンテナの基準方向＝機首などから時計回り）、仰角0〜90°の**全組合せ**に利得（dBi）が必要です。方位が1点だけなら方位に依存しない表になります。仰角は2点以上です。
- 1表30万点・6 MiBまで、登録50件まで。同じ名称は登録できません。プリセットから参照中の表は削除できません。
- 計算のたびに、回線方向（TXは受信局、RXは送信局への大圏方位）から基準方向を引いた角度で表を切り出し、1〜30 MHz×仰角0〜90°へ線形補間して、VOACAPのType 14（地点間用の周波数×仰角利得表）として渡します。表の範囲外の周波数・仰角は端の値を使います。
- 基準方向は主放射方向の欄で指定し、「相手局へ向ける」では基準方向が相手局を向きます（機首を相手局へ向けた状態）。
- 利得補正はType 14の最大利得欄（パラメーター1）に入り、表の全値へ加算されます。地面定数・寸法は使いません。地面の影響は表に含めてください（自由空間の表ならその前提の計算になります）。
- 結果の`parameters`には、使った表のSHA-256（`{tx,rx}_pattern_sha256`）と切り出し角度（`{tx,rx}_pattern_offset_deg`）を残します。
- 機体の高度・姿勢の変化、表に含まれない整合・給電損失は再現しません。VOACAPは両端を地表近くの局として電離層伝搬を計算します。

## VOACAP入力との対応

| VOACAPの入力 | 指定元 |
|---|---|
| アンテナ種別・パターン（ANTENNAカードのファイル） | プリセットの基準モデル |
| 最大利得／ダイポール比利得（パラメーター1・7・8） | プリセットの利得補正。利得の欄がないType 43（ログペリ）・38（逆L）・41（スローパー）では、TX・RXの補正値をTXカードの電力へ換算して加えます（VOACAPの雑音はアンテナ外部の値なので、信号とSNRへの効果は同じです） |
| 比誘電率・導電率（パラメーター3・4） | プリセットの地面定数（寸法付きモデルのみ） |
| 全長・地上高／給電点高（パラメーター6・7） | プリセットの寸法（実寸m） |
| ログペリの給電点高・最長素子長・傾斜・給電線インピーダンス・素子先端角・τ・素子数（Type 43のパラメーター6〜12） | プリセットのログペリ項目 |
| 逆Lの水平部長・垂直部高（Type 38のパラメーター6・7） | プリセットの全長・高さ |
| スローパーの傾斜・線長・給電点高（Type 41のパラメーター6〜8） | プリセットの線の傾斜・全長・高さ |
| 主ビーム方位（beam_main） | 指向性プリセットの主放射方向（固定方位または相手局方向）。全方向モデルは0 |
| 利得表（Type 14の周波数×仰角利得） | 登録した利得表を回線方向で切り出した値。カードのbeam_mainは0 |
| 動作周波数（パラメーター5）・設計周波数 | エンジンが計算周波数ごとに設定。寸法を実寸mで渡すため固定値は不要 |
| 対象周波数範囲（2–30 MHz） | 計算可能な周波数範囲と同じ固定値 |
| 送信電力 | 計算条件（アンテナではなく送信機の設定） |
| 最低打上げ角 | 計算条件のSYSTEMカード（VOACAPでは回線全体の値でアンテナごとではない） |

基準ホイップ（swwhip）の効率−4.8 dBと仰角パターンは同梱ファイルの値を使い、編集しません。基準ホイップ・等方性では寸法・地面定数・方位を使いません。
