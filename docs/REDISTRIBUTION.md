# 再配布手順と同梱物

この手順はソースと通知を同時に添付する方式です。ダウンロードURLの案内だけや、
「必要なら後で対応ソースを公開する」という約束だけを配布手段にしません。
最終的な利用形態・地域・契約に応じた法務確認は別途行ってください。

## 配布物の生成

Docker（マルチステージビルド対応）、Git、Python 3、ネット接続が必要です。
変更をコミットし、作業ツリーをクリーンにしてリポジトリのルートで実行します。

```sh
python3 scripts/build_redistribution.py dist/redistribution
```

既存の出力ディレクトリは上書きしません。新しい名前を指定してください。
Linux amd64とarm64は別のビルド・別の配布束で検証します。このスクリプトは実行環境のネイティブCPU向けに作成します。

成功した場合に限り、以下を含むディレクトリが生成されます。

| 同梱物 | 内容 |
|---|---|
| runtime-image.tar | finalステージのみ。中間ステージ・ビルドキャッシュは含めない |
| application-source.tar.gz | 同じGitコミットの現在ツリー。エンジンのビルド可能なソース・係数・補助部品・Dockerfile・独自コード・ライセンス全文 |
| licenses/ | 本体MIT・外部データ条件・第三者通知・Python原文・全Debianパッケージの通知・GPL/LGPL等の参照全文・実在庫 |
| corresponding-sources/sources/ | 全Debianランタイムパッケージの正確なソース版（.dscと参照アーカイブ等）、CPythonソース、取得物ハッシュ一覧 |
| corresponding-sources/runtime-inventory.json | ソース取得の対象とした実在庫。実行イメージ側と一致しない場合は生成を中止 |
| SHA256SUMS.json | 配布ファイルのSHA-256 |

**ディレクトリ全体を同じ配布先へ渡してください。runtime-image.tarだけを切り離して配布しないでください。**
対応ソースにはDebianのパッチ・パッケージ構築情報も含め、Python本体・内包部品の原文を保持します。
CPythonソースからは最終イメージにないensurepipディレクトリと内包wheelを除外し、変更を明記します。

## 停止する条件

- 未監査CPU、パッケージ追加・削除・版変更、copyright本文の変更、Python版・原文の変更。
- 監査外のPythonディストリビューションがsite-packagesに残存。
- 指定版のDebianソース、CPythonソースが取得できない、CPythonの公開SHA-256と不一致。
- イメージとソース収集ステージの実在庫が不一致。
- 最終イメージ内の再監査または全回帰テストが失敗・スキップ（ネットワークを隔離し、外部APIはテスト用応答を使用）。
- Dockerがない／起動できない、作業ツリーに未コミットの変更がある。

パッケージの追加・更新時は、ライセンス・依存物・対応ソースの取得方法を確認し、ロックを更新してください。
ロック更新だけで法的な許諾が増えるわけではありません。セキュリティ更新を無期限に止める用途にも使わないでください。
Debianの配信から指定版ソースが消えた場合、無関係な最新版で代用せず、正確な版を確保するまで配布を保留します。

## 受領者に伝える事項

- 本体MITと第三者部品の条件を分け、著作権・免責・原文の許諾を保持すること。
- 該当GPL/LGPL部品の対応ソースと構築情報が同梱されていること。
- ライブラリの改変・差替えや、そのデバッグに必要な権利を独自契約で一律禁止しないこと。
- 本体・エンジンの精度、実回線の可用性、外部APIの継続提供を保証しないこと。
- 外部データの再配布は別条件であり、データボリュームをこの束へ追加しないこと。
- この手順で中間ステージ、ビルドキャッシュ、Git履歴全体を配布しないこと。

削除したロゴ・マニュアルは以前のGit履歴に残っています。履歴を遡って同梱しないでください。
実運用の認証設定・秘密情報を含めてはいけません。
ゲートウェイは本体と同じ監査対象イメージを別コマンドで起動します。ゲートウェイのソースも同じGitアーカイブに含まれます。
hf-dataに加えgateway-dataボリューム、外部受信用・本体連携用の両トークンも配布物から除外してください。
ゲートウェイ管理パスワード`HF_GATEWAY_UI_PASSWORD`も配布物に含めません。アンテナの公開資料はURLと限定的な事実値・独自注記のみを収録し、外部の図面・写真・PDF・実測パターンは同梱しません（[詳細](ANTENNA_PRESETS.md)）。

## 現時点の状態

AI設定ファイル`ai-settings.json`とOpenAI／Claude／Gemini／ローカル接続用のキーも配布対象外です。ローカルLLMのモデル・サーバーは同梱しておらず、利用する各モデル・サーバーの条件は別途適用されます。

生成AI OCR用の`OPENAI_API_KEY`、取り込んだカタログ・仕様書の原本と抽出結果も配布物へ含めません。これらはhf-dataボリューム内で管理し、通常の配布束にボリュームを追加しない運用を維持します。

ソースの条件とamd64/arm64の固定OCIベース＋追加ランタイムの通知を照合済み。
実エンジンをLinux上で再コンパイルし、除外後の計算・HTTP APIの回帰確認を実施。
一方、Dockerビルドとこの配布束の実生成は未実施です。生成成功までは配布用完成物とは扱いません。
