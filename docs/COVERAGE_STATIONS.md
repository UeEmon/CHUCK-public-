# 送信所の重ね合わせ

追加日: 2026-11-14

TXと、地点プリセットから選んだ最大3か所の送信所について、同じ範囲・同じ格子でカバー範囲を計算して重ねます。
格子点ごとに最も届く送信所の色で地図を塗り、どの送信所でも目標RELに届かない所を空白域（灰色）として示します。
海岸局の網で海域全体を覆えているか、どこに空白が残るか、送信所を増やすとどこが埋まるかを確かめるための機能です。

## 操作

1. 右側でTXとRX1を選びます。RX1のアンテナ・雑音が受信側の条件になります。メッシュでは使えません。
2. 「予測条件・宇宙天気」で年月、SSN、周波数（最大11波）、要求SNR、目標RELなどを設定します。
3. 「カバー範囲」タブで範囲（全世界または120°・60°・30°四方）を選びます。範囲の中心は、TXと追加した送信所の中間です。
4. 「送信所を重ねる」で、地点プリセットから送信所を1〜3か所選びます。TXとRX1の地点、移動局は選べません。
5. 「送信所を重ねて計算」を押します。計算中は進み具合を表示し、中止できます。
6. 「表示の切り替え」で次を選びます。再計算はしません。
   - 表示：「最も届く送信所」（送信所の色と空白域）または「最良のREL %」（どの送信所でも最も高いREL）
   - 周波数：「最良周波数」（格子点ごとに、すべての送信所・周波数の中で最も高いREL）または1つの周波数
   - UTC：スライダーまたは「▶ 再生」
7. 地図の格子を選ぶと、その地点の最良の送信所、（最良周波数では）その周波数、RELを表示します。

地図の◆は計算した送信所の位置です。

## 面積の表

地図の下の表は、表示中の周波数・時刻について、範囲内の面積に占める割合（緯度の余弦で重み付け、%）を示します。
地点間のRELではありません。

| 列 | 内容 |
|---|---|
| 単独で目標REL以上 | その送信所だけで目標REL以上になる面積 |
| 最も届く範囲 | 目標REL以上の所のうち、その送信所が最も高いRELになる面積（地図でその色の部分） |
| この送信所だけが届く範囲 | ほかのどの送信所でも目標RELに届かず、その送信所だけが届く面積。その送信所を外すと空白になる部分です |
| 全送信所 | どれかの送信所で目標REL以上になる面積 |
| 空白域 | 100 − 全送信所 |

## 判定の規則

- 格子点ごとに、RELが最も高い送信所を選びます。RELが同じならSNRが高い方、それも同じならTX・選んだ順の先の送信所です。
- 最良周波数では、送信所ごとに格子点ごとの最良の周波数（REL、同じならSNR、それも同じなら低い周波数）を選んでから、送信所を比べます。
- 最良の送信所のRELが目標REL未満の格子点が空白域です。

## 計算量

送信所ごとに、カバー範囲の計算（周波数×24時間、6時間分ずつ1回）を行うため、エンジンの実行回数は送信所の数×周波数の数×4回です。
格子は全世界で91×91（経度4°・緯度2°）、それ以外で61×61です。全世界・4か所・11波では、4コアのサーバーで数分かかります。
公開版では回数制限のコストが60です。

## 限界

- 追加した送信所は、TXのアンテナ（種類・利得・向き）と送信電力で送信すると仮定します。送信所ごとに違うアンテナ・電力は指定できません。
  TXのアンテナを「経路の方向」に向けている場合、追加した送信所でもその送信所からRX1への方位に向けます。
- 同じ周波数で複数の送信所が同時に送信したときの混信、受信側での送信所の切替は考慮しません。
- RELは月間統計です。空白域は、モデルの上で目標RELに届かない所を示すもので、実際に受信できないことを保証しません。
- 利得表アンテナは、カバー範囲と同じく使えません。
